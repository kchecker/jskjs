llms.txt for jsKjs

Any model that can read a URL can learn jsKjs in one request. /llms.txt is the index; /llms-full.txt is everything.

Open llms-full.txtOpen llms.txt

llms.txt is a proposed convention: a Markdown file at a site's root that tells language models what the site is and where the important pages are. jsKjs publishes two:

  • /llms.txt — a short summary plus links to every feature, guide and comparison.
  • /llms-full.txt — the complete agent rules and API in one file (the same text as AGENTS.md).

Tell an agent with web access: “Read https://jskjs.org/llms-full.txt, then build …”. For agents without web access, use the rules files instead.
