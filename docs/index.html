Compatibility notesThe core follows jQuery 3.7 semantics and passes 1,119 of 1,131 of jQuery's own unit tests (98.9%). $.ajax() returns a jqXHR, handlers receive a jQuery.Event, and jQuery selector extensions (:visible, :eq(), :contains()) work. Collections also extend Array, so forEach, includes and for…of work too. Full list: migrating from jQuery and comparisons.

Core & selectors

Core & selectors

Everything starts with $(). jsKjs implements jQuery 3.7's API; a collection is also a real Array subclass, so for…of, spread and native array methods work. $.fn.jquery reports "3.7.1" so jQuery plugins accept it.

$()

$(selector [, context]) · $(element | elements) · $(html [, attrs]) · $(fn)

Select with any CSS selector (native querySelectorAll) or jQuery's extensions (:visible, :hidden, :contains(), :first, :last, :eq(n), :even, :odd, :lt(), :gt(), :input, :checkbox…, [a!=b], leading > + ~). Also wraps nodes, creates elements from HTML and runs a function on DOM ready.

JavaScript
$('.card')                    // CSS
$('li:visible:first', '#menu') // jQuery extensions + context
$('<a>', { href: '/x', text: 'Go' })
$(() => console.log('ready'));

See it live: Selectors & collections →

.each()

.each((index, element) => {}) → self

Iterate the collection. this is the element; return false to stop.

JavaScript

See it live: Selectors & collections →

.map()

.map((index, element) => value) → collection

jQuery's map: returns a new collection (arrays are flattened, null dropped). Call .get() for a plain array.

JavaScript

.get()

.get([index]) → element | element[]

A plain array of the elements, or one element (negative indexes count from the end).

AJAX

AJAX

jQuery's $.ajax: a jqXHR with .done/.fail/.always/.then, every option, global events, $.ajaxSetup, prefilters, transports, converters and JSONP. It is a thenable, so await works: it resolves with the data and a failure throws the jqXHR.

$.ajax()

$.ajax(url [, options]) · $.ajax(options) → jqXHR

All jQuery options (type/method, data, dataType, headers, timeout, cache, contentType, processData, beforeSend, statusCode, xhrFields…). jsKjs extra: json: true sends data as JSON.

JavaScript
try {
  const user = await $.ajax({ url: '/api/user', dataType: 'json', timeout: 5000 });
} catch (xhr) { console.log(xhr.status, xhr.statusText); }

See it live: AJAX with $.ajax →
