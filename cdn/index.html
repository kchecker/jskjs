Why pin?An integrity hash only matches one exact file. The versioned URLs never change, so the hash stays valid and browsers can cache them for a year. The “latest” URLs will change with each release — never combine them with integrity.

Self-hosting

Copy jskjs.min.js next to your pages and reference it with a relative path. It has no dependencies and needs no build step. If you serve it cross-origin with SRI, send Access-Control-Allow-Origin: *. The source is also on GitHub.
