Hyper · htmx-style

Request lifecycle events

Every Hyper request announces itself: kj:before, kj:after, kj:error, then kj:load once new content is in place. They bubble, so one listener on document sees them all.

EventFires onWhendetail
kj:beforerequesting elementbefore the request{ url, verb }
kj:afterrequesting elementresponse received, before the swap{ url, verb, html }
kj:errorrequesting elementnetwork error or non-2xx status{ url, verb, error } (error.status)
kj:loadtarget (or its parent, if outerHTML replaced it)after the swap{ url, verb }

JavaScript
const t0 = performance.now();
const log = (name, text) => $('#lc-log').text(
  ('+' + Math.round(performance.now() - t0) + 'ms  ' + name.padEnd(10) + text + '\n' + $('#lc-log').text()).split('\n').slice(0, 9).join('\n'));
let inflight = 0;

$(document).on('kj:before', (e, d) => {
  inflight++;
  $('#lc-progress').css({ opacity: 1, width: '70%' });
  log('kj:before', d.verb.toUpperCase() + ' ' + d.url);
});
$(document).on('kj:after', (e, d) => log('kj:after', d.url + ' (' + d.html.length + ' bytes)'));
$(document).on('kj:error', (e, d) => {
  log('kj:error', d.url + ' → HTTP ' + d.error.status);
  $('#lc-target').text('Something went wrong (HTTP ' + d.error.status + '). Try again.');
});
$(document).on('kj:load', e => log('kj:load', '#' + e.target.id + ' updated'));

$(document).on('kj:after kj:error', () => {
  if (--inflight > 0) return;
  $('#lc-progress').css('width', '100%');
  setTimeout(() => $('#lc-progress').css({ opacity: 0, width: '0%' }), 450);
});

API
kj:before · kj:after · kj:error · kj:load
kj:before (before the request), kj:after (response received, before the swap; detail.html) and kj:error (detail.error.status) fire on the requesting element. kj:load fires on the target after the swap — or on its former parent when outerHTML replaced it. All bubble.
Reference: Lifecycle events →

  
Migrating
Coming from htmxRough equivalents: htmx:beforeRequest → kj:before, htmx:afterRequest → kj:after, htmx:responseError → kj:error, htmx:afterSwap → kj:load. Events are not cancelable.
