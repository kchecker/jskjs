Targets & swaps

kj-target says where; kj-swap says how. Watch all eight strategies land around the same element.

kj-target takes any CSS selector (default: the element itself). kj-swap picks the insertion strategy:

kj-swapEffectTypical use
innerHTMLReplace the target's content (default)Panels, results
outerHTMLReplace the target itselfEdit-in-place rows, delete (empty response)
beforeendAppend insideFeeds, chat, "load more"
afterbeginPrepend insideNewest-first lists
beforebegin / afterendInsert as a siblingInline forms, notices
textContentInsert as plain textCounters, untrusted text
noneMake the request, change nothingFire-and-forget, analytics

More examples

Patterns

HTML
<!-- Chat: append each new message -->
<form kj-post="/chat/send" kj-target="#messages" kj-swap="beforeend">…</form>

<!-- Delete a row: server returns an empty body, the row disappears -->
<button kj-delete="/rows/9" kj-target="#row-9" kj-swap="outerHTML">Delete</button>

<!-- Track a click without touching the page -->
<a href="/pricing" kj-post="/track?e=pricing" kj-swap="none">Pricing</a>

API

kj-target="#selector"

Where the response HTML goes (default: the element itself).

Reference: kj-target →
kj-swap="innerHTML | outerHTML | textContent | beforebegin | afterbegin | beforeend | afterend | none"

How the response is inserted into the target. outerHTML replaces the target entirely; the four position values insert adjacent to it; none makes the request without touching the DOM.

Reference: kj-swap →

Migrating

Coming from htmxSame swap names. htmx swap modifiers (swap:1s, settle, scroll:top, show), hx-select and out-of-band swaps (hx-swap-oob) are not included.
