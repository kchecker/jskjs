Motion · GSAP-style

Classic effects

Your old .fadeIn(400) and .slideToggle() calls keep working — same names, same milliseconds, same callbacks — running on the Motion engine.

These shims exist so jQuery code migrates without edits. They use milliseconds (jQuery's unit), accept a completion callback with this bound to each element, and return the collection for chaining. .slideDown() measures the element's natural height, so it works with dynamic content.

For new code, prefer $.to() and await — they are more flexible and composable.

JavaScript
// Accordion: one open at a time
$('#fx-faq').on('click', '.fx-q > button', function () {
  const open = $(this).attr('aria-expanded') === 'true';
  $('#fx-faq .fx-q > button').not(this).attr('aria-expanded', 'false').next().slideUp(200);
  $(this).attr('aria-expanded', String(!open)).next().slideToggle(200);
});

$('#fx-show').on('click', () => $('#fx-notice').fadeIn(300));
$('#fx-dismiss').on('click', () => $('#fx-notice').fadeOut(300));

$('#fx-upload').on('click', function () {
  const full = $('.fx-track').width();
  $(this).prop('disabled', true);
  $('#fx-status').text('Uploading…');
  $('#fx-bar').css('width', 0).animate({ width: full }, 1200, 'power2.inOut', () => {
    $('#fx-status').text('Upload complete ✓');
    $(this).prop('disabled', false);
  });
});
