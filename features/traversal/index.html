DOM traversal

Move around the tree from wherever you are: up with .closest(), down with .find(), sideways with .siblings(), and narrow down with .filter() and .not().

Traversal methods return new, de-duplicated collections, so you can chain them freely. .filter(), .not() and .is() accept a selector, an element, a collection, or a predicate function (index, element) => boolean.

.closest() is the workhorse of event handling: from the element that was clicked, climb to the card, row or form that owns it. It is built on the native Element.closest().

JavaScript
const $start = $('#anchor-node');
const methods = {
  siblings: () => $start.siblings(),
  next:     () => $start.next(),
  prev:     () => $start.prev(),
  parent:   () => $start.parent().closest('li'),
  parents:  () => $start.parents('.branch'),
  find:     () => $('#tree').find('.leaf'),
  filter:   () => $('#tree .leaf').filter('.special'),
  notfn:    () => $('#tree .leaf').not((i, el) => el.textContent.includes('B')),
};

$('#trav-buttons').on('click', 'button', function () {
  $('#tree li').removeClass('hit');
  const $result = methods[this.dataset.m]();
  $result.addClass('hit');
  $('#trav-out').text($(this).text() + ' → ' + $result.length + ' element(s)\n' +
    'start.is(".leaf") = ' + $start.is('.leaf') + ' · start.is(".special") = ' + $start.is('.special'));
});

Migrating
Coming from jQueryCore traversal matches jQuery. .nextAll(), .prevAll(), .nextUntil(), .parentsUntil(), .has(), .contents(), .end() and .addBack() are not included.
