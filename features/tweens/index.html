Motion · GSAP-style

Tweens

$.to(target, { x: 200, rotate: 15, duration: .6, ease: 'back.out' }). Seconds, not milliseconds; transforms, not left/top; a Promise you can await.

The tween engine

Every frame runs on requestAnimationFrame. Transform shorthands — x, y, rotate, scale, scaleX, scaleY, skewX, skewY — are tracked per element and composed into a single transform write per frame, so animating x never clobbers a rotate set earlier.

Any other numeric CSS property (opacity, width, margin-left, stroke-dashoffset) tweens from its computed value. Options: duration (seconds, default 0.4), delay, ease, stagger and onComplete.

Respect prefers-reduced-motion: check matchMedia('(prefers-reduced-motion: reduce)') and skip or shorten decorative tweens.

JavaScript
const SIZE = 44;
$.each($.easings, name => $('<option>').text(name).appendTo('#tw-ease'));   // every built-in easing
$('#tw-ease').val('back.out');
$('#tw-dur').on('input', function () { $('#tw-dur-v').text(this.value); });

async function moveTo(x, y) {
  const ease = $('#tw-ease').val(), duration = +$('#tw-dur').val();
  $('#tw-out').text("await $.to('#tw-ball', { x: " + Math.round(x) + ', y: ' + Math.round(y) +
    ', duration: ' + duration + ", ease: '" + ease + "' })");
  await $.to('#tw-ball', { x, y, duration, ease });
  $.fromTo('#tw-ball', { scale: 1.3 }, { scale: 1, duration: .3, ease: 'elastic.out' });   // land with a wobble
}

$('#tw-arena').on('click', function (e) {
  const r = this.getBoundingClientRect();
  moveTo(Math.min(Math.max(e.clientX - r.left - SIZE / 2, 0), r.width - SIZE),
         Math.min(Math.max(e.clientY - r.top - SIZE / 2, 0), r.height - SIZE));
});

$('[data-corner]').on('click', function () {
  const r = $('#tw-arena')[0].getBoundingClientRect(), c = this.dataset.corner;
  moveTo(c.includes('r') ? r.width - SIZE : 0, c.includes('b') ? r.height - SIZE : 0);
});

API
$.to(target, { …props, duration, delay, ease, stagger, onComplete }) → Promise
Tween to a state. stagger offsets each element’s start; onComplete fires after the last finishes. Also chainable on sets: $(sel).to(props).
Reference: $.to() →
ease: name | (t) => number
Built in: linear, ease-in, ease-out, ease-in-out, power2.in, power2.out, power2.inOut, back.out, elastic.out, bounce.out — exposed as $.easings — or pass any function mapping 0→1 progress.
Reference: Easings →

  
Migrating
Coming from GSAPgsap.to() → $.to(), same property names and seconds. Not included: repeat/yoyo, playback control on single tweens, colour and SVG-attribute tweening, onUpdate, and automatic overwriting of competing tweens.
