Core · jQuery-compatible

Classes & CSS

Class lists and inline styles, the jQuery way — with first-class support for CSS custom properties, so one .css('--accent', …) can re-theme a whole component.

Classes for state, variables for tuning

Use classes for discrete states (open, compact, error) and CSS custom properties for continuous values (hue, radius, progress). .css() writes custom properties with setProperty and never appends px to them, so .css('--hue', 200) means exactly 200.

For ordinary properties, numbers become pixels automatically — except unitless ones such as opacity, z-index and line-height. Reading a property returns the computed value.

JavaScript
const $pv = $('#preview');

function report(note) {
  $('#css-out').text(note + '\n' +
    "css('--accent-h')     → " + $pv.css('--accent-h') + '\n' +
    "css('border-radius')  → " + $pv.css('border-radius') + '\n' +
    "hasClass('compact')   → " + $pv.hasClass('compact') + '\n' +
    "hasClass('elevated')  → " + $pv.hasClass('elevated'));
}

$('#t-hue').on('input', function () {
  $pv.css('--accent-h', this.value);     // custom property: no px added
  $('#t-hue-v').text(this.value);
  report('One custom property re-themes border, badge, button and shadow.');
});

$('#t-rad').on('input', function () {
  $pv.css('--r', this.value + 'px');
  $('#t-rad-v').text(this.value);
  report('Radius flows to every corner through calc().');
});

$('#t-compact, #t-shadow').on('click', function () {
  const cls = this.id === 't-compact' ? 'compact' : 'elevated';
  $pv.toggleClass(cls);
  $(this).attr('aria-pressed', String($pv.hasClass(cls)));
  report(".toggleClass('" + cls + "')");
});

report('Drag a slider or toggle a class.');

Common patterns
JavaScript
$('.tab').removeClass('active').eq(2).addClass('active');
$('#menu').toggleClass('open', isOpen);          // force on/off
$('.bar').css({ width: 240, opacity: .8 });       // width → 240px, opacity stays .8
$(':root').css('--brand', '#6c5ce7');             // theme the whole page

.css(name [, value]) · .css(object) → string | self
Get a computed style from the first element, or set styles on all. Numbers become px except for unitless properties. Custom properties (--name) are read with getPropertyValue and written without px.
