Forms & serialization

.serialize() gives you name=Ada&plan=pro; .serializeObject() gives you { name: 'Ada', plan: 'pro' }. Both read the browser's own FormData.

Because serialization uses FormData, it follows the browser's rules exactly: disabled fields are skipped, unchecked checkboxes are omitted, and multi-selects contribute one entry per selected option (.serializeObject() keeps the last; use new FormData(form).getAll(name) for all of them).

Prefer HTML? <form kj-post="/api/save"> does the same thing with no JavaScript at all — see declarative requests.
