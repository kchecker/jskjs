Confirmations & loading indicators

One attribute asks "Are you sure?"; another shows a spinner while the request runs. The requesting element gets aria-busy="true" for free.

kj-confirm="Delete invoice #1001?" shows the browser's native confirm dialog and cancels the request if the user declines. kj-indicator="#spinner" shows the named element for the duration of the request and hides it afterwards.

While a request is in flight the element carries aria-busy="true", which assistive technology understands and which you can style: [aria-busy="true"] { opacity: .6; cursor: progress; }.

API

kj-confirm="message"

Show a native confirm dialog before requesting.

kj-indicator="#selector"

Element to show while the request is in flight (the trigger also gets aria-busy="true").

Migrating

Coming from htmxhx-confirm → kj-confirm. jsKjs shows/hides the indicator element itself rather than toggling an htmx-request class; hx-disabled-elt is not included.

Declarative requests

Request lifecycle events

Every declarative request emits bubbling lifecycle events — kj:before, kj:after, kj:error and kj:load — so one document-level listener can drive a page-wide progress bar or error toast..
