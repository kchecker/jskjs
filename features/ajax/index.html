AJAX with $.ajax

The familiar $.ajax() options, powered by fetch. Await it, or keep your success and error callbacks — both work. Try it against live PHP endpoints below.

Promises first, callbacks welcome

$.ajax() returns a native Promise, so await and try/catch just work. For migrating code it also accepts success, error and complete callbacks, and the promise carries .done(), .fail() and .always().

Options

url, method (or jQuery's type), data (object, FormData or string), json: true to send a JSON body, dataType ('json' or 'auto'), headers, timeout in milliseconds (aborts automatically), and credentials. Failed responses reject with an Error carrying .status and .data; the promise also exposes .abort().

JavaScript
$('#ax-send').on('click', async () => {
  const started = performance.now();
  $('#ax-status').text('Sending…');
  try {
    const data = await $.ajax({
      url: $('#ax-url').val(),
      method: $('#ax-method').val(),
      data: { name: $('#ax-name').val(), plan: 'pro' },
      json: $('#ax-json').val(),                       // checkbox .val() → boolean
      timeout: +$('#ax-timeout').val() || undefined,
    });
    $('#ax-status').html('<span class="yes">✓ OK</span> in ' + Math.round(performance.now() - started) + ' ms');
    $('#ax-out').text(typeof data === 'string' ? data : JSON.stringify(data, null, 2));
  } catch (err) {
    const why = err.name === 'AbortError' ? 'aborted by timeout' : 'HTTP ' + err.status;
    $('#ax-status').html('<span class="no">✗ ' + why + '</span>');
    $('#ax-out').text(err.data || err.message);
  }
});

API
$.ajax(url | options [, options]) → Promise
Full-control requests. Options: url, method (or jQuery’s type), data (object → urlencoded or querystring; FormData; string), json: true (send JSON body), dataType (’json’ | ’auto’), headers, timeout (ms, auto-aborts), credentials, and callbacks success(data, status, res), error(err), complete(). The promise also has .abort().

Migrating
Coming from jQueryReturns a Promise rather than a jqXHR. $.ajaxSetup, prefilters, transports and JSONP are not included; set shared headers with a small wrapper function instead.
