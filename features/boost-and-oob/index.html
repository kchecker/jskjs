Hyper · htmx-style

Boost & out-of-band swaps

One response, many updates: the main content goes to the target, and anything marked kj-swap-oob replaces the element with the same id elsewhere on the page.

kj-boost

Put kj-boost="true" on a container and its links and forms become AJAX requests that swap into body (or the inherited kj-target) and push the URL to history. Without JavaScript they still work as normal links — progressive enhancement for free.

Out-of-band swaps

Any top-level element in a response with kj-swap-oob="true" is pulled out and swapped into the element with the same id. Use a swap style (kj-swap-oob="beforeend:#log") to append instead of replace. kj-select-oob does the same from the requesting side, and $.hyper.oob(html) runs it from JavaScript.

    Migrating

    Coming from htmxhx-boost, hx-swap-oob and hx-select-oob behave the same as kj-boost, kj-swap-oob and kj-select-oob; responses written for htmx (with hx-swap-oob) also work.
