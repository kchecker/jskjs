Motion · GSAP-style

Transforms

Move with x/y, spin with rotate, grow with scale, lean with skewX — each independently, composed into one GPU-friendly transform.

Writing style.transform by hand means every animation must know every other: set a rotation and you lose the translation. jsKjs keeps each component per element and rebuilds translate() rotate() scale() skew() on every frame, so you can tween y on hover while a separate tween spins the same element.

Transforms don't trigger layout, which is why they stay smooth on phones. Prefer them to left, top, width and height whenever you can.

JavaScript
const state = { x: 0, y: 0, rotate: 0, scale: 1, skewX: 0 };
const show = () => $('#tf-out').text("style.transform → '" + $('#tf-card')[0].style.transform + "'");

$('#tf-ctrls').on('input', 'input[type=range]', async function () {
  state[this.dataset.prop] = +this.value;
  $(this).prev().find('span').text(this.value);
  await $.to('#tf-card', { ...state, duration: .25, ease: 'power2.out' });
  show();
});

$('#tf-spin').on('click', async () => {
  await $.to('#tf-card', { rotate: state.rotate + 360, duration: .8, ease: 'power2.inOut' });   // only rotate changes
  $.to('#tf-card', { rotate: state.rotate, duration: 0 });
  show();
});

$('#tf-reset').on('click', async () => {
  Object.assign(state, { x: 0, y: 0, rotate: 0, scale: 1, skewX: 0 });
  $('#tf-ctrls input[type=range]').each(function () {
    $(this).val(state[this.dataset.prop]).prev().find('span').text(state[this.dataset.prop]);
  });
  await $.to('#tf-card', { ...state, duration: .5, ease: 'back.out' });
  show();
});
show();

API
$.to(target, { …props, duration, delay, ease, stagger, onComplete }) → Promise
Tween to a state. stagger offsets each element’s start; onComplete fires after the last finishes. Also chainable on sets: $(sel).to(props).
