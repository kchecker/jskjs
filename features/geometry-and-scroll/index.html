Core · jQuery-compatible

Geometry, scroll & visibility

Measure anything, scroll anything, show and hide anything — with the same calls you used in jQuery, built on getBoundingClientRect and the native scroll APIs.

Measurements you can trust

.width() and .height() return the rendered size from getBoundingClientRect(), including transforms; on $(window) they return the viewport. .offset() gives page coordinates (scroll included) — perfect for positioning popovers — while .position() is relative to the nearest positioned ancestor.

Scrolling

.scrollTop() and .scrollLeft() read and write scroll position on elements and on $(window). Pair them with $.throttle() for scroll-driven UI such as progress bars and scroll-spy.

Visibility

.hide() remembers the element's previous display value, so .show() restores flex or grid instead of forcing block.

JavaScript
const $panel = $('#geo-panel');

function measure() {
  const max = $panel.prop('scrollHeight') - $panel.prop('clientHeight');
  const pct = max ? $panel.scrollTop() / max : 0;
  $('#geo-progress').css('width', (pct * 100).toFixed(1) + '%');
  const off = $panel.offset();
  $('#geo-out').text(
    'scrollTop() → ' + Math.round($panel.scrollTop()) + 'px of ' + max + 'px\n' +
    'width()     → ' + Math.round($panel.width()) + 'px · height() → ' + Math.round($panel.height()) + 'px\n' +
    'offset()    → { top: ' + Math.round(off.top) + ', left: ' + Math.round(off.left) + ' }');
}

$panel.on('scroll', $.throttle(measure, 50));
$(window).on('resize', $.throttle(measure, 100));

$('#geo-nav').on('click', '[data-to]', function () {
  const $section = $panel.children('section').eq(+this.dataset.to);
  $panel.scrollTop($section.position().top - 8);    // position() is relative to the panel
});

$('#geo-toggle').on('click', function () {
  $panel.toggle();
  const open = $panel.css('display') !== 'none';
  $(this).attr('aria-expanded', String(open)).text(open ? 'Hide panel' : 'Show panel');
});

API
.width([value]) · .height([value]) → number | self
Measured size (from getBoundingClientRect) or set the CSS size. On $(window), returns the viewport size.
Reference: .width() / .height() →
.offset() → { top, left }
Position relative to the document, including scroll.
Reference: .offset() →
.position() → { top, left }
Position relative to the offset parent.
Reference: .position() →
.scrollTop([value]) · .scrollLeft([value]) → number | self
Get or set scroll position. Works on elements and on $(window).
Reference: .scrollTop() / .scrollLeft() →
.show() · .hide() · .toggle([state]) → self
Instant visibility via display. .hide() remembers the previous display value so .show() restores it correctly.
Reference: .show() / .hide() / .toggle() →

  
Migrating
Coming from jQuery.innerWidth()/.outerWidth() and the .offset() setter are not included; read getBoundingClientRect() or set top/left with .css().
