Motion · GSAP-style

Timelines

Choreography without callback pyramids. Steps run in order; '<' starts a step together with the previous one; '+=0.3' waits a beat first.

PositionMeaning
(none)Start after everything before it has finished
'<'Start at the same time as the previous step
'+=0.3'Start 0.3 s after the previous step finishes

Defaults passed to $.timeline({ ease, duration }) apply to every step. Timelines auto-play; pass paused: true and call await tl.play() when you want to control the start and know when it ended. .add(fn) runs any function as a step — and if it returns a Promise, the timeline waits for it.

JavaScript
const log = s => $('#rk-log').text(($('#rk-log').text() + '\n' + s).trim());
const count = n => () => { $('#rk-count').text(n); log('T-' + n); };
const beat = { scale: 1, opacity: 1, duration: .55 };

$('#rk-go').on('click', async function () {
  $(this).prop('disabled', true);
  $('#rk-log').text('');
  const tl = $.timeline({ paused: true, ease: 'power2.out' })
    .add(count(3)).fromTo('#rk-count', { scale: 1.7, opacity: 0 }, beat)
    .add(count(2)).fromTo('#rk-count', { scale: 1.7, opacity: 0 }, beat)
    .add(count(1)).fromTo('#rk-count', { scale: 1.7, opacity: 0 }, beat)
    .to('#rk-count', { opacity: 0, duration: .15 })
    .to('#rk', { x: -4, duration: .05 }).to('#rk', { x: 4, duration: .05 }).to('#rk', { x: 0, duration: .05 })
    .to('#rk-flame', { opacity: 1, scaleY: 1.7, duration: .25 })
    .to('#rk', { y: -250, duration: 1.4, ease: 'power2.in' })
    .to('#rk-flame', { y: -250, duration: 1.4, ease: 'power2.in' }, '<')    // flame rides along
    .add(() => log('Liftoff ✓'), '+=0.1')
    .fromTo('#rk-msg', { y: 14, opacity: 0 }, { y: 0, opacity: 1, duration: .4 });
  await tl.play();                                                          // resolves when every step is done
  $(this).prop('disabled', false);
});

$('#rk-reset').on('click', () => {
  $.to('#rk, #rk-flame', { x: 0, y: 0, scaleY: 1, duration: .3 });
  $('#rk-flame, #rk-msg').css('opacity', 0);
  $('#rk-count').text('');
  $('#rk-log').text('');
});

API
$.timeline({ paused?, onComplete?, ...defaults }) → timeline
Sequence tweens. Steps run in order; position '<' starts a step with the previous one; '+=0.3' waits 0.3 s first. Methods: .to(), .from(), .fromTo(), .add(fn) (waits if fn returns a Promise), .play() → Promise. Auto-plays unless paused: true.
