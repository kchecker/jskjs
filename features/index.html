Features

Core

Selectors & collections

Use $() exactly like jQuery — CSS selectors, context, HTML creation and DOM-ready — powered by native querySelectorAll, with collections that are real JavaScript arrays..

DOM manipulation

Insert, move, clone, wrap and remove elements with the jQuery API you know — .append(), .prepend(), .before(), .after(), .clone(), .empty() — on modern DOM primitives..

Live demo →Core

Attributes, properties & data

Read and write HTML attributes, live DOM properties and per-element data.

Classes & CSS

Toggle classes and set styles with addClass(), toggleClass() and css() — including CSS custom properties, which jsKjs reads and writes without adding px..

Live demo →Core

Geometry, scroll & visibility

Measure and position elements with width(), height(), offset() and position(), control scrolling with scrollTop(), and show or hide elements without losing their display value..

Live demo →Core

DOM traversal

Walk the DOM with find(), closest(), parent(), parents(), children(), siblings(), next(), prev(), filter(), not() and is() — every result chainable and de-duplicated..

Live demo →Core

Events

Bind and unbind events with on(), off() and one(), group handlers with namespaces like click.menu, and use shortcut methods — the jQuery event API on native addEventListener..

Event delegation

Handle clicks on thousands of rows — including rows added later — with a single listener using .on(event, selector, handler).

Custom events

Decouple your UI with custom events: trigger("cart:add", payload) once and let any number of independent listeners react.

AJAX with $.ajax

jQuery's $.ajax rebuilt on fetch: native Promises and async/await, JSON bodies, headers, timeouts with auto-abort, plus success/error callbacks and .done/.fail for migration..

Live demo →Core

$.get, $.post & $.getJSON

One-line GET, POST and JSON requests that return Promises: await $.getJSON(url), $.get(url, data), $.post(url, data) — live examples against real endpoints..

Loading HTML fragments

Forms & serialization

Turn forms into query strings or plain objects with serialize() and serializeObject(), then submit them with $.post — or declaratively with kj-post..

Timeouts, aborts & retries

Handle real-world network failure: HTTP errors with status codes, automatic timeouts, manual abort(), and a retry-with-backoff helper — demonstrated against live endpoints..

Declarative requests

Make GET, POST, PUT, PATCH and DELETE requests straight from HTML with kj-get, kj-post and friends — htmx-style hypermedia with zero JavaScript.

Targets & swaps

Live demo →Hyper

Triggers & debouncing

Choose when requests fire with kj-trigger: any DOM event plus a debounce like keyup delay:400ms — live search and server-side inline validation without JavaScript..

Polling

Lazy loading & infinite scroll

Load content when it scrolls into view with kj-trigger="revealed", or immediately with kj-trigger="load".

Confirmations & loading indicators

Ask before destructive requests with kj-confirm and show progress with kj-indicator.

Sending extra data

Send more than the element itself: kj-include adds another form's fields, kj-vals adds literal JSON values.

History & deep links

Request lifecycle events

Every declarative request emits bubbling lifecycle events — kj:before, kj:after, kj:error and kj:load — so one document-level listener can drive a page-wide progress bar or error toast..

Timelines
