Pulse · Alpine-style

Two-way binding

kj-model="r" keeps a control and a state property in sync — both ways. Move a slider and the state changes; change the state and the slider moves.

kj-model works with text, number, range, textarea, select, checkbox (booleans) and radio buttons (the checked radio's value). It never rewrites the field you are typing in, but programmatic changes — a preset button, a reset — update it immediately.

The mixer below binds the hex field to a getter/setter pair: reading hex computes it from the three channels, writing a valid hex parses it back into them. That is all two-way binding needs.

JavaScript
$.component('mixer', () => ({
  r: 108, g: 92, b: 231,
  get hex() {
    return '#' + [this.r, this.g, this.b].map(n => (+n).toString(16).padStart(2, '0')).join('').toUpperCase();
  },
  set hex(value) {                                       // typing a valid hex updates all three sliders
    const m = /^#?([0-9a-f]{6})$/i.exec(String(value).trim());
    if (m) [this.r, this.g, this.b] = [0, 2, 4].map(i => parseInt(m[1].slice(i, i + 2), 16));
  },
  rgb() { return 'rgb(' + this.r + ', ' + this.g + ', ' + this.b + ')'; },
  luminance() {
    return [this.r, this.g, this.b]
      .map(v => { v /= 255; return v <= .03928 ? v / 12.92 : Math.pow((v + .055) / 1.055, 2.4); })
      .reduce((sum, v, i) => sum + v * [.2126, .7152, .0722][i], 0);
  },
  contrast() { return +(1.05 / (this.luminance() + .05)).toFixed(2); },
  ink() { return this.contrast() >= 4.5 ? '#FFFFFF' : '#13152B'; },
}));

API

kj-model="property"

Two-way binding for text, number and range inputs, textareas, selects, checkboxes (booleans) and radio buttons (the checked radio’s value). The field being typed in is never rewritten mid-typing; programmatic changes update it immediately.

Migrating

Coming from Alpine.jsx-model → kj-model. Values arrive as strings (use +value); Alpine's .number, .lazy and .debounce modifiers are not included.
