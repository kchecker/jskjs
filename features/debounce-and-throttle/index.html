Debounce & throttle

Move your pointer over the pad. Raw events flood in; $.throttle() lets one through every 200 ms; $.debounce() waits until you stop.

  • Throttle — run at most once per interval while events keep coming. Use for scroll and resize handlers, drag, progress bars.
  • Debounce — run once, after events stop for the interval. Use for search-as-you-type, autosave, validation.

Both return a new function that preserves this and arguments, so they drop straight into .on(). For declarative requests, kj-trigger="keyup delay:300ms" debounces without any JavaScript.

JavaScript
const WINDOW = 4000;
let t0 = performance.now();
const counts = { raw: 0, thr: 0, deb: 0 };

function tick(lane) {
  const now = performance.now();
  if (now - t0 > WINDOW) { t0 = now; $('.dt-lane > div').empty(); }   // start a new 4 s window
  counts[lane]++;
  $('#n-' + lane).text(counts[lane]);
  $('<i>').css('left', ((now - t0) / WINDOW * 100).toFixed(2) + '%').appendTo('#lane-' + lane);
}

const throttled = $.throttle(() => tick('thr'), 200);
const debounced = $.debounce(() => tick('deb'), 300);

$('#dt-pad').on('pointermove keydown', () => { tick('raw'); throttled(); debounced(); });

Typical uses

JavaScript
$(window).on('scroll', $.throttle(updateProgressBar, 50));
$('#search').on('input', $.debounce(function () { search(this.value); }, 300));
$(window).on('resize', $.debounce(relayout, 150));

API

$.debounce(fn [, wait = 300]) → fn

Returns a function that fires only after calls stop for wait ms.

$.throttle(fn [, wait = 300]) → fn
