jsKjs vs jQuery

jsKjs implements the jQuery API most code actually uses — on native browser features — and adds three more modules. Here is exactly where it matches, differs and stops.

Choose jsKjs when…
  • You target evergreen browsers and want the jQuery API without the legacy weight.
  • You also need declarative requests, reactive state or real animation — without three more libraries.
  • You want native Promises, fetch and WeakMap-based data by default.
Choose jQuery when…
  • You must support Internet Explorer 11 or other pre-2021 browsers.
  • You depend on jQuery plugins that use internals ($.fx, $.Deferred, ajax prefilters/transports).
  • You rely heavily on the fx queue (.stop(), .delay(), .queue()).
