Core · jQuery-compatible

The $ you know

Selectors, traversal, events, delegation, AJAX — the jQuery API, on native browser features. Your muscle memory works on day one; collections are real arrays.

Live · Delegation in six lines

jskjs 1.0.0
  • Click an item to strike it
  • New items work too
View the source for this demo
HTML
<form id="h-form" class="row"><label for="h-in" class="sr-only">New item</label><input id="h-in" type="text" placeholder="Add an item…" style="flex:1;min-width:160px"><button type="submit">Add</button></form>
<ul id="h-list" class="list-plain"><li>Click an item to strike it</li><li>New items work too</li></ul>
JavaScript
$('#h-form').on('submit', e => {
  e.preventDefault();
  if ($('#h-in').val()) $('<li>').text($('#h-in').val()).appendTo('#h-list');
  $('#h-in').val('');
});
$('#h-list').on('click', 'li', function () { $(this).css('text-decoration', 'line-through').fadeOut(500); });

Hyper · htmx-style

Requests in your HTML

    Pulse · Alpine-style

    State that lives on the element

    Declare state with kj-data, bind it with kj-text, kj-show, kj-model and @click. Change the data and the page follows — no build step, no virtual DOM.

    Motion · GSAP-style

    Motion with taste

    Tweens, transforms, ten easings, stagger and timelines on requestAnimationFrame — with Promises you can await. Seconds, like GSAP; classic fadeIn() still works.

    Measured, not guessed

    A twelfth of the weight

    The official builds of the four libraries total 90.2 KB gzipped. jsKjs is 8.1 KB, because it targets evergreen browsers and ports the parts most sites use. See exactly what's included.

    Built for AI agents

    Tell your agent “use jsKjs”.

    One documented API instead of four, HTML you can review at a glance, and nothing to build. Ready-made rules for every major coding agent.

    One mental model, not four

    An agent asked to add "live search with a fade-in" to a jQuery + htmx + Alpine + GSAP page must juggle four APIs, load orders and overlapping ideas of state.
